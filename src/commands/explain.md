# /sparklogs-explain

Explain the evidence behind this SparkLogs finding or claim: `{{args}}`.

Use the `sparklogs-investigate` skill (if not yet run). Walk through the cited `query_url`s behind the claim and what each one showed, what evidence would refute it, and what was not checked. If the claim lacks evidence, say so and name the query that would supply it. Cause analysis stays in `/sparklogs-analyze-cause`.
