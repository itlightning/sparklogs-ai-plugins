# Origin fields

**Use when:** finding where a connection or sign-in came from, by address, host name or port.

| Field | Type | Unit | Meaning |
|---|---|---|---|
| `sparklogs.origin.ip` | string |  | The initiating endpoint's IP address. |
| `sparklogs.origin.host` | string |  | The initiating endpoint's host name as logged. |
| `sparklogs.origin.port` | string |  | The initiating endpoint's port as logged. |
| `sparklogs.origin.port_name` | string |  | The service category associated with the port. |
